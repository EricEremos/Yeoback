# Yeoback

## Register

product

The GitHub README is a brand surface for this product.

## Users

Mac users whose AI and developer work leaves growing caches, SVG drafts, exports, and work records. They need to find candidates and understand them before removal.

## Product Purpose

Make storage review actionable: inspect files, clean supported caches, remove eligible applications, compare folder growth, and monitor a chosen free-space reserve. The reserve is a target, not a guarantee.

## Brand Personality

Deliberate, understandable, distinctive. Yeoback takes its name from 여백, the room around what matters. The existing storage-volume icon and native system typography anchor its identity. See [the implemented design contract](docs/github/DESIGN.md).

## Anti-references

Generic AI marketing copy, decorative capacity claims, repetitive badge walls, and deletion controls without file evidence. A screenshot must show the actual app; a filename clue must not become a claim of verified AI origin or safe removal.

## Design Principles

- Show the product before describing its architecture.
- Use concrete file and workflow examples.
- Keep selection, review, execution, and outcomes distinct.
- Distinguish measured capacity, candidate estimates, and reserve targets.
- Preserve the icon's ivory, evergreen, and coral palette across appearances.

## Accessibility & Inclusion

Use selectable text for essential information, descriptive image alternatives, readable mobile compositions, native controls, and non-color status labels. Existing bounded checks are recorded in [Quality](docs/github/QUALITY.md); full accessibility and participant usability validation remain open.

## Provenance

Derived from the selected Yeoback identity, existing project foundation, implemented design contract, and the user's request for a concise, visually compelling public product presentation. This consolidates established decisions; it does not claim new participant research.
